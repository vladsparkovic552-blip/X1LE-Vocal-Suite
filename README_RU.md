# X1LE Vocal Suite

VST3-плагин для Windows x64, собранный на JUCE 8.

## Автоматическая сборка
Каждый push в ветку main запускает GitHub Actions. Также сборку можно запустить вручную во вкладке Actions.

После успешной сборки скачайте artifact **X1LE-Vocal-Suite-Setup**. Внутри ZIP находится установщик `X1LE_Vocal_Suite_Setup.exe`.

## Установка
1. Запустите установщик.
2. Разрешите установку в системную папку VST3.
3. Перезапустите FL Studio.
4. В FL Studio откройте Plugin Manager и выполните поиск плагинов.

## Управление
INPUT, GATE, PRESENCE, AIR, COMP, DE-ESS, DRIVE, MIX, OUTPUT.

Это первая версия процессора. Настройки обработки зависят от исходной записи; начните с небольших значений и сравнивайте звук с bypass.
