SoulSound 2.9.0 VST3 installer

Place the original SoulSound_beta_2.9.0_1118_0004.zip archive in this folder, then run INSTALL.bat. The script requests administrator rights, validates the x64 VST3 bundle, backs up an existing installation, and copies SoulSound.vst3 into %CommonProgramFiles%\VST3.

After installation, rescan plugins in FL Studio: Options > Manage plugins > Find installed plugins.
